> [!KEY] 擴散模型學的是「**去噪**」——訓練時把圖片一步步加雜訊，再教模型預測被加了什麼雜訊；生成時從純雜訊開始，反覆去噪，就長出一張新圖。

## 這講在學什麼

文字可以一個 token 接一個 token 生成，但圖片沒有天然的「下一個像素」順序。擴散模型換了一個思路：不是一塊一塊畫，而是**整張圖一起，從模糊到清楚**慢慢修出來。這是目前圖像生成的主流方法。

## 前向過程：把圖變成雜訊

**前向擴散**（Forward Process）很簡單，不需要學：

1. 拿一張真實圖片 `x_0`。
2. 每一步加一點高斯雜訊，得到 `x_1, x_2, …, x_T`。
3. 加到第 `T` 步（例如 1000 步），圖片已經變成幾乎純雜訊。

> [!TIP] 好消息是不用真的一步步加：可以直接算出任意第 `t` 步的樣子——`x_t = √ᾱ_t · x_0 + √(1−ᾱ_t) · ε`，其中 `ε` 是隨機雜訊、`ᾱ_t` 是事先排好的係數。訓練因此很有效率。

## 反向過程：學會去噪

**反向過程**（Reverse Process）才是模型要學的：給它一張加過雜訊的圖 `x_t` 和步數 `t`，請它**預測當初加進去的雜訊 `ε`**。

- 預測得準 → 把雜訊扣掉，就往乾淨的圖前進一步。
- 從純雜訊 `x_T` 開始重複這個動作，最後得到 `x_0`：一張全新的圖。

> [!EXAMPLE] 像雕刻：一塊大理石（雜訊）裡本來沒有雕像，但雕刻師每一刀都「去掉不屬於雕像的部分」，最後雕像就出現了。

> [!WARNING] 擴散模型不是把訓練圖片「存起來再拼貼」。它學的是去噪的規則；不過如果某張圖在訓練資料中重複太多次，模型確實可能生成非常相似的結果，這是著作權討論的焦點之一。

## 用文字控制畫面：條件與 CFG

光會去噪只能生出「隨便一張合理的圖」。要讓它聽話：

- **文字條件**：把 prompt 用文字編碼器（例如 CLIP 的 text encoder）轉成向量，在去噪時透過交叉注意力（Cross-Attention）餵給模型。
- **Classifier-Free Guidance（CFG）**：同時算「有 prompt」和「沒有 prompt」兩種預測，再把差距放大。

| CFG 數值 | 效果 |
|---|---|
| 低（約 1–3） | 比較自由、多樣，但可能不太照 prompt |
| 中（約 5–9） | 常見預設區間，平衡 |
| 高（> 12） | 很照 prompt，但容易過飽和、不自然 |

## Stable Diffusion 的架構

Stable Diffusion 屬於**潛在擴散模型**（Latent Diffusion Model），不在像素上去噪，而是在壓縮後的潛在空間裡：

| 元件 | 工作 |
|---|---|
| VAE 編碼器／解碼器 | 圖片 ↔ 潛在向量（壓縮與還原） |
| 文字編碼器 | 把 prompt 轉成向量 |
| U-Net（或新版的 Transformer, DiT） | 在潛在空間中預測雜訊、反覆去噪 |
| 排程器（Scheduler） | 決定總共幾步、每步去掉多少雜訊 |

> [!NOTE] 上一講的 Transformer 也走進了圖像生成：以 Transformer 取代 U-Net 的 **DiT**（Diffusion Transformer）是近年新模型常見的骨幹。

## 重點整理

- 前向過程：逐步加雜訊，不需要學習。
- 反向過程：模型學預測雜訊，從純雜訊反覆去噪生成新圖。
- 文字透過文字編碼器 + 交叉注意力控制生成；CFG 決定「多聽 prompt 的話」。
- Stable Diffusion 在潛在空間去噪，所以比直接處理像素快很多。

## 自我檢測

<details>
<summary>Q1. 擴散模型在訓練時，模型實際要預測的是什麼？</summary>

預測被加進圖片的**雜訊** `ε`（給定加噪後的圖 `x_t` 與步數 `t`）。預測出雜訊後就能把它去掉。

</details>

<details>
<summary>Q2. 生成圖片時，為什麼 CFG 開太高圖片會怪怪的？</summary>

CFG 會把「有 prompt」與「無 prompt」預測的差距放大。放大太多時，模型被過度推向 prompt 的方向，容易出現顏色過飽和、細節扭曲等不自然的結果。

</details>

<details>
<summary>Q3. Stable Diffusion 中 VAE 的角色是什麼？</summary>

負責壓縮與還原：生成前把圖片（或訓練資料）編碼到潛在空間，去噪完成後再把潛在向量解碼回看得見的圖片。

</details>
